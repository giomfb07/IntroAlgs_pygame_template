# Imagens

Pasta destinada a sprites, fundos, icones e outros elementos visuais.

## Conteudo atual
- `fundo_fase1.png`: plano de fundo da Fase 1.
- `fundo_fase2.png`: plano de fundo da Fase 2.
- `fundo_fase3.png`: plano de fundo da Fase 3.
- `fundo_fase4.png`: plano de fundo da Fase 4.
- `Slime1_Run_body.png`: spritesheet do personagem principal (Slime), inspirado no asset *Top Down RPG Slime Creatures Pixel Art*. Link: https://opengameart.org/content/top-down-rpg-slime-creatures-pixel-art
- `Magical_rainbow_star.png`: sprite da recompensa coletável do jogo, inspirado no asset *Life Heart and Rainbow Star GIFs*. Link: https://opengameart.org/content/life-heart-and-rainbow-star-gifs
- `spritesheet.bmp`: conjunto de sprites utilizado na composição dos cenários e elementos visuais do jogo.

## Recomendações

- Separe imagens por tema quando o projeto crescer.
- Mantenha dimensoes e padroes consistentes para facilitar colisao e animacao.
- Prefira formatos com transparencia quando necessario (ex.: `.png`).
